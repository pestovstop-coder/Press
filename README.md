# Press Office Tycoon

**Жанр:** management / tycoon simulator с фиксированной изометрической 3D-камерой.  
**Движок:** Godot 4.x. **3D:** Blender.  
**Текущий этап:** новый визуально-технический прототип. Старый Phaser-прототип не является основой разработки.

## Концепция
Игрок руководит пресс-службой крупной компании: распределяет работу, принимает решения по поручениям, управляет ресурсами и отвечает за последствия для руководства, общественности и команды.

## Три независимых показателя
- **Доверие руководства** — считает ли руководство пресс-службу полезной и управляемой.
- **Общественное доверие** — доверяют ли аудитория и СМИ компании и её коммуникациям.
- **Состояние команды** — может ли команда работать без постоянной перегрузки.

Это независимые показатели. Решения должны иметь разные последствия для каждой стороны.

## Визуальная концепция
Офис — полноценная 3D-сцена с фиксированной ортографической камерой под изометрическим углом. Мебель, техника, стены и персонажи — 3D-модели. Объекты должны корректно выглядеть при перемещении и повороте без подготовки отдельных PNG-ракурсов.

Основной ориентир — стилизованный low-poly: читаемые силуэты, простые формы, ограниченная палитра, аккуратные материалы и мягкие тени. Не стремиться к фотореализму.

Blender используется для создания моделей. В Godot импортируются модели и анимации через glTF/GLB. Временные бесплатные ассеты допустимы, если их лицензия разрешает использование в проекте.

## Принцип разработки
Сначала проверяем комнату, камеру, мебель, персонажа, навигацию и базовые анимации. Затем проверяем взаимодействие персонажа с рабочим местом. Только после успешной приёмки фундамента начинаем симуляцию рабочего дня.

Документация описывает целевую структуру и решения проекта, а не утверждает, что функции уже реализованы.
