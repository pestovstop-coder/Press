# TASK 007 — Placement Mode State Separation

> TASK 008 добавляет исключение для Ctrl+ЛКМ в PLACING: следующий preview остаётся
> активным. Обычный ЛКМ и MOVING сохраняют правила ниже. Выбор теперь использует
> реальные треугольники и препятствия комнаты: [актуальные детали](TASK_008_INTERACTION.md).

Актуальные состояния редактора Godot; заменяют непрерывную установку TASK 002/006.
Документы Phaser/2D не определяют эту механику. Новые модели, архитектура каталога,
коллизии и сохранения не добавляются.

## Состояния

Флаг `active` отвечает только за открытие режима, сетку и панель.
`EditorState` явно разделяет операции:

| Состояние | Preview | ЛКМ в комнате | Esc |
|---|---|---|---|
| `IDLE` — ничего не выбрано | Нет, `preview == null` | Мебель: начать перемещение; пустота: ничего | Выйти |
| `PLACING` — установка | Отдельный временный экземпляр | Подтвердить ровно один новый объект, затем IDLE | Удалить preview, затем IDLE |
| `MOVING` — перемещение | Сам выбранный объект, полупрозрачный | Подтвердить transform без дубликата, затем IDLE | Восстановить исходный объект, затем IDLE |

Вход через B всегда открывает IDLE. Кнопки панели запускают только PLACING,
но не создают установленную мебель. Повторное нажатие кнопки отменяет предыдущую
операцию (включая rollback перемещения) и начинает новую установку.
В PLACING клик по другой мебели подтверждает установку, а не переключает на
перемещение: пересечения по-прежнему допускаются.

R действует только в PLACING/MOVING. B из любого состояния отменяет операцию и
закрывает режим. После любой установки, подтверждения или отмены:
`preview == null`, `editing == null`, `selected_asset == ""`, угол 0,
`valid_target == false`, записи ghost-материалов очищены.

Временный preview сначала скрывается и восстанавливает свои дублированные
материалы, затем удаляется через `queue_free()`. При перемещении сам объект
никогда не удаляется: подтверждение восстанавливает материалы и тени, отмена
дополнительно восстанавливает исходный мировой transform и видимость, даже
если объект был скрыт над панелью или за пределами пола.
Нового preview после завершения операции не создаётся.

Сохранены привязка 0,5 м, размеры из мешей, учёт поворота на краях пола,
приблизительный picking мешей, панель из двух кнопок и управление камерой.
MMB блокирует подтверждение и picking, отпускание MMB передаётся камере до GUI.
Клики панели не подтверждают размещение. Удаления мебели нет.

## Smoke-тест и ручная приёмка

В установленном Godot 4.7.x из корня проекта:

```sh
godot --headless --path . --editor --quit
godot --headless --path . --script res://tests/placement_smoke.gd
```

Расширенный smoke-тест написан, но здесь не запущен. Он проверяет переходы,
сигналы кнопок и обработчики на настоящей сцене/GLB, точное восстановление
transform, ссылок материалов, surface overrides и режима теней. Он не заменяет
проверку GUI и мыши в окне. Ожидаемый итог: `Placement smoke test failures: 0`.

Все следующие runtime-сценарии остаются непроверенными в данной среде:

1. B: сетка/панель видны, preview нет. Несколько кликов по пустоте ничего не создают.
2. Кнопка блока: preview появляется, но объект не установлен. R/курсор работают.
3. ЛКМ ставит один блок и убирает preview. Дополнительный пустой клик не создаёт блок.
4. Повторная кнопка нужна для второго блока. Выбор стола аналогичен; размер и origin сохранены.
5. Установка повёрнутого стола оставляет обычный стол без активного preview.
6. Клик по исходному и новому столу из IDLE начинает MOVING.
7. R/курсор/ЛКМ перемещают тот же экземпляр, без дубликата, затем IDLE.
8. Esc после перемещения и поворота возвращает исходные transform, материалы и тени.
9. Esc при установке убирает preview и остаётся в режиме; следующий Esc выходит.
10. Выбор другой кнопки во время перемещения сначала возвращает мебель на место.
11. Выход B из установки/перемещения не оставляет ghost; повторный вход снова IDLE.
12. Край пола/курсор над панелью/недопустимая точка не подтверждают операцию;
    выход из скрытого preview восстанавливает перемещаемый объект.
13. Панель не ставит мебель; MMB не выбирает и не подтверждает; камера WASD/MMB/зум/Home
    работает как раньше. Выйти из режима и проверить отсутствие UI/сетки/прозрачной мебели.
