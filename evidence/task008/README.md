# TASK 008 — доступные доказательства

- `static_checks.txt` — результаты доступных статических проверок.
- `offline_mesh_checks.txt` — независимые лучевые проверки реальных треугольников
  `office_desk.glb` на Python, не Godot runtime. Воспроизведение:
  `python3 tests/desk_ray_data_check.py` из корня репозитория.

Godot отсутствует; загрузка бинарника 4.7.2 не удалась из-за сетевого запрета
на сервере файлов GitHub (`curl: (35) SSL_ERROR_SYSCALL`).

**Нет скриншотов/видео Godot, нет выполненного smoke-теста, импорта или компиляции
GDScript движком. Исправление кликов GUI и все 11 пользовательских сценариев
TASK 008 требуют runtime-проверки.** Smoke-тест расширен для них и включает
GUI-события Viewport, а не только прямую отправку сигналов кнопок.

Полные инструкции и ограничения: [TASK_008_INTERACTION.md](../../docs/TASK_008_INTERACTION.md).
