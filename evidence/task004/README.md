# TASK 004 — office_desk

## Результат

Настоящий полигональный GLB 2.0, не Godot BoxMesh и не изображение вместо модели.
Создан офлайн с помощью Python / Trimesh 5.2.0, NumPy и SciPy.
`tools/build_office_desk.py` — специализированный редактируемый источник только
этого ассета; не скрипт Godot и не универсальная система импорта.
Blender отсутствует, не устанавливался; `.blend` не создан и не заявлен.
Godot 4.7.x отсутствует, импорт и runtime **НЕ ПРОВЕРЕНЫ**.

## Конструкция и проверка

- 9 деталей, 396 треугольников: столешница 40 мм, четыре металлические ножки
  сечением 45 мм, четыре балки опорной рамы под столешницей.
- Геометрия с фасками: 5 мм на столешнице, 1,5 мм на металле.
- Два встроенных PBR-материала без текстур: `light_natural_wood` и `graphite_metal`.
- Габариты X/Y/Z: 1,6 / 0,75 / 0,8 м; ширина × глубина × высота: 1,6 × 0,8 × 0,75 м.
- AABB: минимум (−0,8; 0; −0,4), максимум (0,8; 0,75; 0,4).
- Корень `office_desk`, единичный transform, origin (0, 0, 0), +Y вверх, +Z перед.
  Симметричный стол; смысл передней стороны зафиксирован именами front/back.
- Каждая исходная деталь замкнута, имеет согласованный обход и положительный объём.
  Детали рамы и ножек намеренно соприкасаются/перекрываются как сборная конструкция;
  модель не заявляется как единый manifold для печати. Для плоских нормалей в GLB
  вершины треугольников разделены; это не отверстия в геометрии.
- GLB повторно загружен Trimesh: число деталей и габариты совпадают с источником.
- Khronos glTF Validator: 0 ошибок, 0 предупреждений, 0 подсказок.
- Один корень, 9 мешей, 2 материала, без камер, света, анимаций, скинов,
  внешних буферов или текстур. Нет потерянных внешних зависимостей.
- Четыре офлайн-ракурса просмотрены; проверены столешница, ножки и нижняя рама.
  Рендер Matplotlib упрощает освещение и не доказывает вид PBR в Godot.

Подробности: [геометрия](geometry_checks.json), [валидатор GLB](gltf_validation.json).

## Подключение в сцене

В `scenes/main.tscn` добавлен ресурс PackedScene с путём к GLB и экземпляр
`TestRoom/OfficeDesk` в (0, 0, 0), без дополнительного поворота и масштаба.
Низ модели Y=0 совпадает с верхом существующего пола Y=0 по статическим данным.
Камера, стены, пол, материалы комнаты, настройки проекта и скрипты не изменены.
Система временных блоков остаётся; стол не подключён к размещению.

Статическая ссылка на GLB **не равна подтверждённому импорту в Godot**.
После открытия проекта установленный Godot должен выполнить импорт GLB.
В Godot 4.7.x ещё требуется проверить Output/Debugger, касание пола,
видимость из существующей камеры и оба материала. Скриншотов комнаты нет.

## Воспроизведение

Зависимости инструмента устанавливаются отдельно от Godot-проекта:
`trimesh==5.2.0`, `numpy`, `scipy`; для изображений дополнительно `matplotlib`.
Из корня репозитория: `python tools/build_office_desk.py --preview`.
Это заново создаёт GLB, отчёт геометрии и офлайн-ракурсы.
Для независимой проверки GLB использован npm-пакет `gltf-validator`;
полный JSON его результата сохранён рядом. Пакеты и окружение не включены в Git.

Файлы небольшие, Git LFS не используется. Следующие ассеты не создавались.
