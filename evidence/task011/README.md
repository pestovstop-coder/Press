На машине с Godot:

```sh
godot --headless --path . --editor --quit
godot --headless --path . --script res://tests/orbit_smoke.gd
godot --headless --path . --script res://tests/placement_smoke.gd
```

`orbit_smoke.gd` проверяет обработчики реальной сцены: четверть-обороты и полный
круг, возврат каждого модуля, неизменность transforms, фокус/радиус/pitch/Home,
MMB/клавиатуру/zoom, guard навигации, луч через скрытую стену к столу и блокировку
видимой стеной. Он также ставит блок, сохраняет Ctrl-style preview, поворачивает
preview стола и отменяет перемещение блока в каждом ракурсе. Это не имитация
полной ручной проверки мышью. Старый placement smoke включает остальные
сценарии стола/блока, R, Esc, Ctrl, UI и восстановления материалов/теней.
Оба теста пока **не исполнены**, наличие проверок не означает успех.

### Обязательная ручная проверка

1. RMB в обе стороны: горизонтальный круг, pitch до обоих ограничений, без
   переворота/ухода под пол. Фокус должен оставаться на месте; после pan вращение
   должно идти вокруг перемещённого фокуса, без скачка при начале жеста.
2. Колесо в обе стороны, MMB, WASD и все стрелки; Home возвращает исходные
   положение, углы, размер и набор видимых стен. Отпустить RMB/MMB над панелью,
   свернуть/вернуть окно: жест не должен залипать.
3. Проверить 0/90/180/270° и полный круг: оба кабинета доступны обзору, дальние
   стороны сохраняются, ближние скрываются, все модули возвращаются. Слегка
   двигать мышью около порогов; не должно быть мерцания. При взгляде вдоль
   перегородки она показывается; задняя стена не имеет дыр на стыках/углах.
4. Проверить все дверные/оконные проёмы: рамки следуют своим стенам, нет отдельных
   зависших элементов и объёмных наложений; пол всегда видим.
5. B → сетка → стол → блок → R → перемещение → Esc → несколько Ctrl+ЛКМ; обычный
   ЛКМ однократный. Проверить после каждого поворота; скрытая стена не мешает
   выбору, видимая мешает. RMB/MMB сами и в комбинации с ЛКМ ничего не подтверждают.
6. Выход из редактора убирает сетку/панель/preview; Esc возвращает перемещаемому
   объекту исходные transform/materials/shadows. Известные hitbox/top-picking
   дефекты TASK 008 остаются открытыми до отдельного исправления.
7. Проверить тени/контакт и их изменение при cutaway: новые источники не добавлены,
   sole caster Sun. Ступенчатые края и баланс света при необходимости вынести
   в отдельную задачу; здесь улучшение не объявляется подтверждённым.
8. Сохранить четыре настоящих скриншота 0/90/180/270° и, по возможности, запись
   непрерывного круга. Не заменять их этими офлайн-иллюстрациями.
